BEFORE YOU PUBLISH
 - Have a South African attorney read the wording, and check your exact registered company name
   on your CIPC certificate (it usually ends in (Pty) Ltd).

PUBLISH ON GITHUB (free)
 1. Use your existing repo (skraal-delights-legal) or create a new PUBLIC one.
    (NEVER make your backend or app repos public.)
 2. Upload ALL files and the assets folder from this folder (keep .nojekyll) -> Commit.
    Replace the old files so the new design and pages go live.
 3. Repo -> Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder: / (root) -> Save.
