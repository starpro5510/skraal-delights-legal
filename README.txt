PUBLISH ON GITHUB (free)
 1. github.com -> New repository -> name: skraal-delights-legal -> PUBLIC -> Create.
    (Use a NEW repo. NEVER make your backend or app repos public.)
 2. Upload all files from this folder (keep .nojekyll) -> Commit.
 3. Repo -> Settings -> Pages -> Source: "Deploy from a branch" -> Branch: main, folder: / (root) -> Save.
 4. After about a minute your site is live at:
      https://<your-github-username>.github.io/skraal-delights-legal/
